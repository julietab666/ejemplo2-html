Descubrí el mundo del Desarrollo Web

¿Te gustaría crear tus propias páginas web desde cero? En esta sección vas a sumergirte en una experiencia practica donde aprenderás a diseñar, programar y construir sitios web modernos.
A través de distintos talleres, vas a conocer las herramientas esenciales que utilizan los desarrolladores hoy en dia, pasando de ideas simples a proyectos interactivos y funcionales.
Es el lugar prefecto para empezar, experimentar y dar tus primeros pasos en el mundo digital.

Talleres disponibles:

  • HTML y CSS
  • JavaScript
  • PHP y MySql

Taller 1: HTML y CSS

En este taller aprenderás a crear y diseñar tus propias páginas web desde cero. Exploremos cómo estructurar contenido con HTML y darle estilo y presonalidad con CSS, logrando sitios visualmente atractivos y organizados. Es ideal para quienes quieren dar sus primeros pasos en el desarrollo web.

Taller 2: JavaScript

Este taller se enfoca en darle vida a las páginas web. Aprenderás los fundamentos de JavaScript para crear interactividad, validar formularios y mejorar la experiencia del usuario. Es el siguiente paso para transformar una web estática en una dinámica.

Taller 3: PHP y MySql

En este taller conocerás cómo funciona el desarrollo web del lado del servidor. Aprenderás a manejar bases de datos con MySql y a conectarlas con PHP como registros de usuarios, formularios funcionales y almacenamiento de información.
